# Iconos de estilos del quiz (opcional)

Si quieren un icono para cada estilo, guárdenlo aquí con **estos nombres exactos**:

| Archivo | Estilo |
|---|---|
| `minimal.png` | Minimal |
| `urbano.png` | Urbano |
| `comfy.png` | Comfy |
| `flow.png` | Flow |

- Formato: **PNG cuadrado con fondo transparente**, de unos 256×256 px, **en blanco** (se ve sobre la franja negra de la tarjeta de estilo).
- Si no existe, simplemente no se muestra (no se rompe nada).
- La **foto de fondo** de cada estilo también se cambia en `js/data/apariencia.js` (`ESTILOS_VISUALES`).
